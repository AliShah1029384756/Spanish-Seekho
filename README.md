# Spanish Seekho 🇪🇸🇵🇰

**Making Spanish Learning Accessible to Every Pakistani.**

Free, mobile-first Spanish learning for Pakistani learners. The learning experience is Roman Urdu-first, with English meanings and Urdu-script pronunciation approximations. The curriculum teaches standard Spanish from Spain (Castilian).

#### A2 starter pathway (23 core lessons + 4 end-of-level activities)
Core lessons 01–23 are available. Topics include past experiences and habits, work and study, travel, opinions, plans, healthcare, directions, present perfect, comparisons, advice and obligation, descriptions, preferences, technology, everyday problems, home and neighbourhood, public services and connected storytelling. The 24 approved core outcomes have been mapped internally; this is not external CEFR validation or a claim of official proficiency.

Separate end-of-level activities are also available: cumulative review and gap repair (25), practical trip project (26), integrated listening/reading/speaking/writing practice (27), and final self-assessment/readiness plan (28). Speaking and writing are self-reviewed, not automatically graded. A2 remains a developing course, not an accredited or complete CEFR qualification.

## Features and limitations
- Homepage language selector has Roman Urdu, Urdu and English copy.
- Lesson pages are primarily Roman Urdu/English supported; Urdu-script pronunciation is approximate. Selecting Urdu on lesson pages changes text direction and saved preference, but does not translate every lesson.
- Browser speech uses an installed Spanish voice where available; device voices and quality vary.
- Progress is stored in localStorage (no account).
- A service-worker cache is configured; offline behaviour still needs real Android/browser smoke testing.
- No paid APIs are required for core learning.

## Principles
Accuracy over volume. Free core learning. Mobile-first. Static HTML/CSS/vanilla JS.

## Curriculum standard

Spanish Seekho's approved long-term target is a 168-module programme across CEFR A1–C2 (28 modules per level). This is our own curriculum structure, not a CEFR-prescribed lesson count. A2 core outcomes have internal mapping evidence; B1 is being expanded in order against the approved map. The full programme is not yet implemented. See the [Curriculum Master Plan](docs/CURRICULUM-MASTER-PLAN.md) for level outcomes, all 168 planned modules, assessment principles and implementation phases.
